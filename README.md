# Blue Capital Venture — Immersive Capital Compass Edition

Replace the `index.html` in the root of your GitHub repository with this file.

The site remains static and Vercel-ready. No build command or extra configuration is required.

## Included experience

- Full-screen animated Capital Compass hero
- Custom canvas-based floating particles, linked data lines and light mist
- 3D-style compass core with orbiting highlights
- Mouse depth/parallax on desktop
- Glass navigation on scroll
- Scroll-led advisory-process journey
- Motion-aware mobile and reduced-motion fallbacks

Commit the replacement to the `main` branch and Vercel will deploy it automatically.
