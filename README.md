# Blue Capital Venture website

This is a static website. No build command or framework is required.

## Files

- `index.html` — the complete website, including embedded styling, scripts, logo and visuals.

## GitHub + Vercel

1. Upload `index.html` to the root of your GitHub repository.
2. In Vercel, open the Blue Capital project.
3. Go to **Settings → Git → Connect Git Repository** and select this repository.
4. Keep the framework preset as **Other** and leave the build command empty.
5. Click **Deploy**.

After that, every commit or change pushed to the `main` branch will automatically update the live website.

## Editing

For future changes, edit `index.html`, commit the changes to GitHub, and Vercel will redeploy automatically.
